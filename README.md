# 🌲 TimberCal - モバイルGIS架線集材シミュレーション・森林現地調査ツール

[![WebGIS](https://img.shields.io/badge/WebGIS-Leaflet%20v1.9.4-brightgreen.svg)](https://leafletjs.com/)
[![GeoTIFF](https://img.shields.io/badge/GeoTIFF-geotiff.js-orange.svg)](https://cdn.jsdelivr.net/npm/geotiff)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**TimberCal** は、森林の現地調査および架線集材（索道開設）の事前計画・シミュレーションを現場のスマートフォンやタブレット上で完結できる、レスポンシブな Leaflet ベースの WebGIS アプリケーションです。

金沢市の基盤地図情報（2m メッシュ DEM）や単木樹木データ (`trees.geojson`) を活用し、主索のたわみ計算、地盤接触判定、集材バッファー範囲内の収穫量（本数・立木材積・搬出材積80%）を即座に自動算定します。

---

## 🌟 主要機能 (Key Features)

### 1. 🗾 高精度マルチベースマップ & 空間オーバーレイ
* **ベースマップ切り替え**:
  * 国土地理院 標準地図
  * 国土地理院 シームレス航空写真 (Seamless Photo)
* **空間分析オーバーレイ**:
  * 📐 **高精細1m 傾斜区分図**: 07HD811 DEMから生成した緩傾斜（<15°）〜極急傾斜（≥45°）の4段階カラーレイヤー（透過率スライダー調整可能）。
  * 🌲 **森林資源20mメッシュ**: 林野庁メッシュタイルの重層表示。
  * **レイヤー重なり順（z-index）の最適化**: 傾斜区分図はベースマップと単木データ/幾何データの中間に配置され、樹木マーカーが隠れません。

### 2. 🌳 単木データ表示 & 樹種凡例
* `data/trees.geojson` (691件) の単木位置マーカー描画（樹種別自動カラーリング）。
* スマホ画面で見やすい小型マーカー (半径 `3.5px`) 表示。
* 左下の折りたたみ凡例パネル (`凡例 ▼`) による樹種一覧・傾斜区分の可視化。

### 3. 📐 架線集材シミュレーション & 縦断面図（プロファイル）
* **2タップ直感操作**: 地図上で始点（元柱/集材機）と終点（先柱/伐採地）を指定。
* **索高自動計算**: 元柱・先柱ともに**地上 +10.0m** の支柱高を標準設定。
* **1.5t 集中荷重たわみ力学計算**:
  * 搬器＋丸太重量（最大 1.5t $\approx$ 14.715 kN）が及ぼす主索の垂下軌跡 $\delta(x)$ をミリメートル精度で解析。
* **【集材可否判定 (地面接触チェック)】**:
  * 主索たわみ線と地盤標高との最小クリアランスを自動判定し、**「⭕ 可能 (最小地上高 〇m)」** または **「⚠️ 不可 (地面接触 ❌)」** をビジュアル表示。
* **スマホ最適化 Canvas 縦断面図**:
  * 縦横比 `2.3 : 1` (max-height: 250px) でレスポンシブ描画。地盤高（緑線）、無荷重直線索（薄橙点線）、1.5t荷重主索たわみ線（赤実線）を同時プロット。

### 4. 📊 集材範囲（幅40mバッファー）& 収穫量自動集計
* 架線軸から左右各 20m（合計幅 40m）の帯状集材エリアを幾何計算し、地図上に自動描画。
* **収穫量の自動算出**:
  * **対象樹木本数**: エリア内部の樹木本数 `[本]`
  * **総立木材積**: 単木材積 (`TANBOKUZAISEKI`) の合計 `[m³]`
  * **搬出材積 (80%)**: 総立木材積 $\times 80\%$ `[m³]`

### 5. 💾 レイヤーコントロールからの GeoJSON エクスポート
* レイヤー設定パネルの「📐 架線集材データ」にある `💾 出力` ボタンから、以下の属性を完全保持した `cable_simulation_YYYY-MM-DD.geojson` をワンクリックで保存：
  * **元柱・先柱 (Point)**: 緯度経度, 地盤標高, 索高(地盤+10m), 柱高(10m)
  * **主索ライン (LineString)**: 水平距離, 主索斜距離, 標高差, 平均傾斜角(°), 平均勾配(%)
  * **集材範囲 (Polygon)**: バッファー幅(40m), 収穫本数, 総立木材積, 搬出材積(80%)

### 6. ℹ アプリ操作ガイド & 公共測量データ出典表記
* 画面右上の `ℹ` ボタンから、操作マニュアルおよび国土地理院基盤地図情報等の著作権・出典表記モーダルを表示。

## 📖 操作方法 (Usage Guide)

1. **基本操作**:
   * ドラッグ・ピンチで拡大縮小。左上の `＋ / －` ボタンでズーム。
   * 右上 `📍` ボタンでGPS現在地を取得。
   * 右上 `🗂` ボタンで背景地図や各種レイヤーを表示・非表示。
2. **架線集材シミュレーション**:
   * 右上 `📐` ボタンを押し、架線モードをオンにします。
   * **1タップ目**: 始点（元柱/集材機位置）を選択。
   * **2タップ目**: 終点（先柱/伐採地位置）を選択。
   * ポップアップ表示される縦断面図で、地形起伏・主索たわみ線・集材可否判定（⭕ / ⚠️）および収穫量を確認します。
3. **GeoJSONエクスポート**:
   * 右上 `🗂` レイヤー設定を開き、「📐 架線集材データ」の横にある `💾 出力` ボタンを押して保存します。

```text
└── docs/
    └── cable_sag_calculation.md # 主索たわみ計算モデル & 集材可否判定仕様書
```
